# 학습 Git 운영
기존 저장소: jy20110929-dot/pknu. 회사 제품 Git과 분리한다.

## 표준 업무
1. Issue에서 이번 학습의 질문·기대결과·완료조건 선택
2. 학습 브랜치에서 자체 코드 및 설명 작성
3. 테스트/실습 실제 결과와 실패도 기록
4. Draft PR로 독립 검토 요청
5. 결과 확인 후 소유자 승인으로 main 병합
6. 진행표 갱신 시 Issue/PR 근거를 연결

## 보고
완료 / 확인 결과 / 문제·위험 / 남은 일 / 대표가 할 일 순으로 짧게 보고한다. 작성만 했으면 문서 작성 완료이지 실습 검증 완료가 아니다.

## Git 안전
- 수업 원본과 회사 코드·데이터·비밀값을 공개 Git에 복제하지 않는다.
- GitHub 원격 브랜치 생성과 사용자의 단말/ORCA 로컬 Worktree 생성은 별개다. 로컬 설정을 했다고 주장하지 않는다.
- 유료 자원, 공개 배포, 권한 확대, main merge는 별도 승인.
- 별도 자동화 등록 없이는 백그라운드에서 진도를 자동 갱신하지 않는다.
