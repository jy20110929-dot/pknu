## 운영
Issue → 학습 브랜치 → 실제 실습 및 검증 → Pull Request → 승인 후 main. 제품 운영 코드·원본 교재·개인정보와 분리합니다. 학습 과제와 작업 기록은 GitHub에서 관리하며, 별도 자동화 없이 자율 실행 중이라고 보고하지 않습니다.

**현재 공개 저장소(public)입니다.** 강사의 원본 파일, 수업 데이터, 회사 코드, 계정·비밀값은 저장하지 않습니다.

기준일: 2026-10-21. 진행 계획 수립과 실습 완료를 구분합니다.
