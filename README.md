# PKNU AI Learning Lab

AI·데이터·서비스 설계 학습을 위한 별도 Git 저장소입니다. 사업 서비스의 코드·배포·계정과 연결하지 않습니다.

## 운영 원칙

- 학습 산출물은 별도 학습 브랜치와 Pull Request(변경 검토 요청)로 관리합니다.
- 메인 브랜치 반영은 소유자 승인 후 수행합니다.
- 수업 원본 파일·비공개 자료·실제 고객 데이터·인증정보는 이 공개 저장소에 업로드하지 않습니다.
- 독자적으로 작성한 학습 노트, 과제, 테스트, 검증 결과만 기록합니다.
- 실행하지 않은 실습은 완료로 표시하지 않습니다.

현재 상태: 초기화 완료. 수업 기반 학습계획은 별도 학습 브랜치에서 관리합니다.
